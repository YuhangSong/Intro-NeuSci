## 2. 这一讲的主线（从模型与验证反推）

多巴胺报的不是奖励，是**误差**；打开盖子，这个误差就是 TD 的 δ；误差规则能解释**阻断**（相关规则不能）；
δ 要写进突触，靠的是配对后几秒的**痕迹窗口**；痕迹够不到的延迟，**评论家（critic）**能把它救回来。

四台仪器 + 一个对照演示串成一条线，`W(t)` 这个窗口函数在第三台和第四台里是**同一个函数**
（代码注释原话：「单棘 e(t)，actor 痕迹逐字复用」）——这是全讲最漂亮的接缝，别在改写时弄丢。

两处折扣率也是同一个：TD 的 γ=0.98 是每 0.1 s 一格，折到每秒就是 0.98¹⁰ ≈ 0.817，正是训练台的 `gammaSec`。

## 3. 四台仪器（参数与判定阈值均以 C4 为准）

### 3.1 `rig-da` · 多巴胺记录台

状态机：ITI（V≡0）→ s0（灯亮）→ s1 … s15，**到达 s15 时给果汁**（dt=0.1 s，即灯后 1.5 s）→ ITI。
幕后引擎 `makeTD()`：α=0.1、γ=0.98、λ=0.97（`lambdaHi`）。

放电：`rate = max(0.5, 5 + 25·δ)` Hz（基线 5 Hz，`daFloor` 0.5 Hz 兜底，所以「坑」是 0.5 Hz 不是 0），
潜伏 60 ms，事件窗 [0.06, 0.26] s，基线窗 [−0.5, 0] s，泊松出脉冲，**判定按 20 个 trial 的 PSTH**。

三个阶段与判定（`burstX` 3、`quietX` 1.6、`dipX` 0.4，都是相对基线窗的倍数）：

| 阶段 | 做什么 | 判据 | 实测通过率 |
|------|--------|------|------------|
| 一 | 不打招呼直接给果汁（无线索 → 无预测 → δ=1） | 果汁窗 ≥3× 基线 | ≥99% |
| 二 | 灯 → 果汁，**隐藏训练 300 试次**（V(s0)≥0.74、V(s14)≥0.99） | 灯窗 ≥3× 且 果汁窗 ≤1.6× | 20 trial ≥96%，40 trial ≥99% |
| 三 | 省略块：每 20 试次省略一次果汁（在线学习，`omitEvery`） | 省略窗 ≤0.4× 且 灯窗仍 ≥3× | ≥99% |

假阳性都已压住：训练后果汁窗被误判成「下陷」≤1%，无事件窗被误判成「爆发」≤1%。
省略块跑完后 V(s14) 仍 ≥0.85（果汁照旧被预测），正常试次 δ(果汁) ≤0.15。

### 3.2 `rig-td` · 打开盖子（TD(λ)）

同一台 TD 引擎，把 α 和 λ 交给学生：α 可调 [0.1, 0.5]（默认 0.3），λ 在 0 与 0.9/0.97 之间切。

- **λ=0（爬行）**：δ 的峰一格一格往前挪——峰至少在 2 个中间站（0.3–1.2 s）停过（`crawlStations`、`midLo`/`midHi`），
  中间峰高 0.15–0.35（看得见的过路峰），120 试次内到灯。α=0.1/0.2/0.3/0.5 四档都成立。
- **λ=0.9 / 0.97（跨越）**：全程中间峰 ≤0.10（`jumpMid`），≤30 试次 δ(灯) 就达 ≥0.35（`jumpCue`），
  收敛后 δ(灯) ≥0.7（理论上限 γ¹⁵≈0.74）。同 α 下到灯的试次数 ≤ λ=0 的三分之一。
- **省略**：练熟（≥30 试次）后省略一次，δ(1.5 s) ≤ −0.6，而 δ(灯) 仍 ≥0.6。
- **迹寿命读数** `tauEff(λ) = dt / ln(1/(λγ))`：λ=0.9 → **0.8 s**，λ=0.97 → **2.0 s**（±0.1）。
  这个读数就是通向下一节的接口——它和单棘窗口是同一个量级。

### 3.3 阻断演示（Rescorla–Wagner；Waelti 2001 的设计）

`rwRun(rule)`：α=0.1；预训练 100 次（A→果汁、B→无），再复合 200 次（AX→果汁、BY→果汁）。

- **误差规则**（各线索预测求和后再算一个共同的误差）：复合首试次 δ≈0（|δ|≤0.01），V_X ≤0.01（**被阻断**），V_Y≈0.5（与 B 平分）。
- **相关规则**（一起出现就各记各的一笔）：V_X ≥0.99——**学生能亲眼看到相关规则给出错误预言**。
- 页面判定口径：`blkX` 0.1、`blkY` 0.4、`corrX` 0.8。
- 附带一条 overshadowing 对照：不预训 A 直接给 AX，V_X≈V_A≈0.5。

（这一段在 C4 里没有分配 rig id，是做成一台小仪器还是一张图 + 一个开关，**未定**。）

### 3.4 `rig-spine` · 单棘窗口（Yagishita 2014）

窗口函数 `W(t) = (t/τ)·e^(1−t/τ)`，τ=0.5 s：峰在 **0.5 s**、峰值 1；W(0.3)≥0.8；**W(2)=0.20**；W(3)≤0.05；W(5)≤0.002；t≤0 时为 0。
读数噪声 SD 0.03（`winNoise`）。

学生要做的是**自己扫出这个窗口的边**：改多巴胺相对配对的延迟，逐点落图，判据取 y<0.2 算「没写进去」。
0.2 / 0.3 / 0.5 s 三种步长下，报出的边都落在 **[1.6, 2.4] s**（`edgeLo`/`edgeHi`）的概率 ≥99%。
两个对照（只配对不给多巴胺 / 只给多巴胺不配对）读数 |x| ≤8%（`ctrlTol`），≥99%。
成图要求：≥7 个点（`minPts`），其中 ≥1 个负延迟、≥3 个落在 [0.3, 2] s 窗内、≥1 个 ≥3 s。

### 3.5 `rig-actor` · 训练台（第三因子的三档）

任务：t=0 灯亮 → t=0.5 s 选边（L/R，softmax，`sigm(wL−wR)`）→ 延迟 Δ（0.5–6 s，步 0.5）→ 选对才给果汁。
更新：**Δw_a = η · Σ_t W(t−0.5) · D(t)**，η=0.3，只动被选中的那一侧（e = x·y，无基线）。
判定：至少 60 试次（`minTrials`），按最近 50 试次（`accWin`）的正确率。

三档第三因子 D：

| 档 | D 是什么 | 现象 | 阈值与实测 |
|----|----------|------|------------|
| `r` | 奖励本身 | Δ≤1.5 s 学得会；Δ 大了痕迹够不到糖 | Δ=0.5/1/1.5：≥90% 正确的通过率各 ≥99%；Δ=2 均值 ≥0.9（窗口边上）；Δ=3 勉强（<70% 占 ≥75%）；**Δ=4/6：100 试次 <70% 占 ≥99%，200 试次仍 ≥95%** |
| `one` | 不管对错都发 +1 | 第一回合乱选出来的那一侧被反复加固，**锁死** | 100 试次内同侧 ≥95%（`lockAcc`）的占 ≥99%；锁左/锁右各 45–55%（不偏心） |
| `delta` | 评论家算出的 δ（α_C=0.3，动作条件化的抽头延迟线） | **把痕迹够不到的延迟救回来** | Δ=4：100 试次 ≥85%（`criticAcc`）占 ≥99%，150 试次 100%；Δ=1/2 同样 ≥99%；Δ=6 在 150 试次 ≥99%；权重不发散（|w|≤20） |

评论家档还有两个可以直接展示给学生的读数：
- **δ 的符号差**：最近 50 试次里，动作后 0.5 s 处的 δ，选错 ≤−0.2、选对 ∈[−0.05, 0.1]（≥90% 种子；实测均值 +0.01 / −0.49）。
- **δ 峰的时刻会搬家**：头两个有奖 trial 的 |δ| 峰在 Δ+0.5 s（果汁时刻，≥95% 种子），第 20 试次起 ≥90% 的 trial 峰搬到 1.0 s（动作后半秒）——
  **第一节那个「爆发从果汁搬到线索」的现象，在这里由学生自己训练出来。**
- 负控：D=r、Δ=4、200 试次能到 ≥85% 的 ≤1%。

页面默认种子 42（`seedOf(n) = |n|·7919 + 13`）；种子 1–12 的最差情形也全部通过（M7 已验）。
